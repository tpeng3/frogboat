Hotato Bot

I was asked to make a bot that calculates word counts of posts on Discord so that’s what this is… It’s based off the code I wrote for QuingeeBot (from the hit RP group Gale’s End)

!!!Mark sure not to post any messages with sensitive information in public channels since this bot has the potential for evil and can log receipts of what people say. Hotato doesn’t store, read or keep any of the data itself but I have to write this disclaimer so Discord doesn't get mad. Please don’t use Hotato for evil!!!

Link to Invite the bot:

/log

Creates a log summary of your messages. By default, it grabs the last 100 non-bot messages in the current channel/thread you’re in. You can specify the fields to customize it a bit more.

thread - What thread or channel the bot should read from (useful for when you want to grab messages from a channel you don’t want to post it.) Sorry, it can’t read archived threads.

start - Paste in a Discord message link for where /log should start reading.

end - Paste in a Discord message link for where /log should end reading.

increasecap - NOTE: by default, /log only grabs the last 100 messages!!! (even if you use “start”) Sorry, Discord limitations. It’s to prevent someone from accidentally exporting an entire OOC or general chat. Because that will make the bot explode. However, you can increase the cap by specifying a number or setting the option to “all” to grab all the messages in an RP thread or channel.

After the command there are two export dropdown options:

  • Markdown files are more readable and can be manually uploaded/imported to Notion page and other places
  • Text files are more viewed like stats since it includes information about the time of post and reactions

/dice

Rolls a random number. Ex: d20 would pick a number between 1-20. You know how DnD dices go. It can add a simple modifier (like “+3”) on top but nothing more than that.

You can also add descriptions to your dice rolls!

/choose

Chooses a random option between a given list of strings. For example:

Typing the choices one | two | three will have the bot pick between “one”, “two”, or “three”. You don’t have to worry if there’s spaces between the | or not, it doesn’t matter.

You can also add descriptions to your choice roll!

/poll

Hold a poll that people can click on buttons to vote for. The results only appear when the person who started the command hits “End Poll”

title - Title of the poll, give context to why you’re holding it

choices - Similar to /choose, the options are seperated by | .

incognito (optional) - If true, the results of the vote gets DMed to the person who started the poll

/signup

Create a signup form where people who react will have their names show up on the form

title - Title of the form, give context to why you’re holding it

groups - Similar to /choose, the options are seperated by | . If you add an emoji in front of the choice (ex: 🌻 Group A | 🌹 Group B) It’ll link that emoji as the one to react with. Otherwise, it’ll default to alphabet emojis as the corresponding react.

description (optional) - Add a description for more details if needed

>ping

You can ping users that reacted to a certain message by grabbing the Discord link after the command. Useful for reminders or a user-run event.

You can also specify the ping to users that reacted to a specific emoji.

>embed

By pasting a link that fills out the following form, you can generate custom embeds that can be decorated with gifs or images.


**AuthorPic:** 
**Author:** 
**Title:** 
**Thumbnail:** 
**Image:** 
**Color:**
**Description:**

AuthorPic - Tiny icon on the top left of the embed, it has to be a valid image link

Author - Text besides the tiny top left icon, this field has to be populated if AuthorPic is used

Title - Bolded text

Color - Color of the line besides the embed. If left empty, it defaults to Hotato’s color (#67A4A6)

Image - Image at the bottom. The size of the image affects the size of the embed.

Description - Supports Discord’s markdown.

Notes:

  • All fields are OPTIONAL besides Description
  • There are no image size recommendations, Discord changes up the styling all the time so nothing is ever consistent.
  • You can react with ❌ to delete any of Hotato’s messages if formatting looks off
  • You can use >embed [Discord message link] as a reply to ping a person with the message
  • Embedded messages support custom emojis that exist in the servers Hotato Bot is part of.
    • Fun fact: they’re in over 300 servers now!
